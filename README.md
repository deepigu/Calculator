# Calculator

Welcome to the Calculator App! This project is a simple calculator implementation using HTML, CSS, and JavaScript. The app performs basic arithmetic operations and is fully responsive for different screen sizes.

# Features
  Perform addition, subtraction, multiplication, and division operations.
  Includes clear and delete buttons for easy input management.
  Responsive design for various screen sizes, making it accessible on mobile, tablet, and desktop.
# Technologies Used
  HTML: Structure of the calculator.
  CSS: Styling and responsiveness.
  JavaScript: Calculation logic and interactivity.
 # How to Use
# 1. Open the Calculator
Open the index.html file in your preferred web browser.
#  2. Perform Calculations
Use the number buttons (0-9) for input.
Use the operation buttons (+, -, *, /) for calculations.
Press the = button to see the result.
# 3. Manage Input
Press the C button to clear the display.
Press the backspace (←) button to delete the last input.
# Customization
  You can customize the calculator by modifying the following:

  Styles: Adjust the styles in the styles.css file.
  Functionality: Explore and modify the JavaScript code in the script.js file to add new features or tweak the behavior.
